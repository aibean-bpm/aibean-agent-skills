01 /

先准备好本地项目

技能不是独立的业务系统。它需要读取你已有的项目结构与代码约定，才能在现有框架上开发。

FRONTEND / WEB

本地 Web 前端

准备包含 package.json、src/ 和 public/form/ 的 Vue 项目。

BACKEND / BIZ

本地 Java 后端

准备包含根 pom.xml 和 aibean-biz-web 模块的 Biz 项目。

两个项目可以是私有的本地仓库，不需要上传到 GitHub。进行接口联调时，还需能访问你的开发环境服务。
02 /

在对话中安装技能

不熟悉终端也没关系。打开 Codex，选择本地项目，再直接告诉智能体从 GitHub 安装技能。

1

打开本地项目

打开 Codex，选择你的 Web 前端和 Biz 后端文件夹，开始一个本地会话。如果当前界面只能先选择一个目录，可先打开其中一个，然后在对话中提供另一个项目的本地路径，并按提示授予访问权限。

2

发送安装请求

复制下面的内容到 Codex 对话框。安装时按 Codex 提示批准所需操作，无需将业务项目上传到 GitHub。

CODEX 对话 / 复制后发送
请从 https://github.com/aibean-bpm/aibean-agent-skills
安装 skills/aibean-business-development 技能到我的 Codex 用户级技能目录。
安装前请先检查是否已经安装；如果已存在，请告诉我并避免覆盖。
安装完成后请告诉我如何开始使用。
3

开启新会话，描述业务需求

等待智能体报告安装成功，然后在 Codex 中开启新会话；指定 Web 与 Biz 的实际本地路径，并使用 $aibean-business-development 提出开发需求。

安装技能可能需要访问 GitHub 和写入本机技能目录；如果 Codex 请求权限，请核对操作内容后授权。若已安装过，请让智能体先检查现有版本，避免覆盖。
备用方式：在终端手动安装（macOS / Linux）

如果对话安装不方便，可以按以下步骤安装。技能仓库与业务源码分开存放。

1

克隆技能仓库

在终端执行。如果目标目录已经存在，请进入该目录更新，或选择其他目录；不要覆盖现有文件。

TERMINAL
git clone https://github.com/aibean-bpm/aibean-agent-skills.git "$HOME/aibean-agent-skills"
2

链接到用户技能目录

先确认目标技能目录不存在；如果已经安装过，请检查现有目录或链接，不要覆盖。

TERMINAL
mkdir -p "$HOME/.agents/skills"
ln -s "$HOME/aibean-agent-skills/skills/aibean-business-development" "$HOME/.agents/skills/aibean-business-development"

这里使用 Codex 的用户级技能目录；也可参考 Codex 技能文档 ↗。

3

打开新的 Codex 会话

在 Codex 中打开你的本地工作区，启动新会话以发现新技能。随后可以在需求中明确输入 $aibean-business-development。

技能通过链接指向克隆目录，请保留该目录。后续在技能仓库执行 git pull 更新，并开启新的 Codex 会话。
03 /

交给 Codex 第一个需求

把前后端的实际本地路径和业务目标一起告诉 Codex。路径由你指定，下方只是格式示例。

PROMPT / 根据实际情况替换路径
使用 $aibean-business-development 技能，帮我开发采购申请业务。

Web 前端项目：/你的本地路径/web
Biz 后端项目：/你的本地路径/aibean-biz

请先阅读现有框架和相关代码，确认所需的表、字段和菜单名称，
再基于现有框架实现查询列表、业务接口和流程表单。
  • 为 Codex 提供两个项目的访问与修改权限；如果目录不在当前工作区，按工具提示添加或授权。
  • 业务 Java 代码沿用 aibean-biz-web；列表沿用项目已有查询面板和表格范式。
  • 在线接口需要认证：技能支持在本地安全输入登录信息，或使用已有临时令牌；不要把密码或令牌发到聊天中。
04 /

涉及流程和表单时

先准备好流程设计器中的流程编码，再让智能体围绕该流程开发业务。流程图与流转功能继续使用平台已有能力。

PROCESS

确认数据与绑定

提供流程编码；智能体查询绑定表和字段。需要新增表或更改字段时，先与你确认；流程表绑定和默认表单写入前会展示请求并征求确认。

FORM

使用本地 Vue 表单

表单直接放在 public/form/forms/。智能体开发时将项目的 public/config.js 中 localform 设为 true，便于本地加载和测试。

产品默认可继续使用远程表单。localform: true 是智能体开发和测试时的本地配置，请留意交付时的配置变更。
  • 流程数据表按平台约定包含 long itemid（唯一主键）和 long taskid（流程引擎写入）。
  • 通过 AutoTable 新建的表，需要按项目要求重启 Biz 服务并确认建表结果。
  • 技能不会设计 BPMN 流程图，也不会重新开发平台已有的待办、审批和流程流转页面。
05 /

开始之前，再确认一下

找不到技能？

检查链接是否指向技能目录，目录内是否存在 SKILL.md，然后启动新的 Codex 会话。

没有流程编码也能开发吗？

普通业务列表和 CRUD 可以正常开发；需要流程关联时，请先在设计器中完成流程并提供编码。

为什么本地表单没有显示？

检查前端实际加载的 public/config.js 中 localform 是否为 true，以及表单相对路径与文件是否一致；配置变化后按项目运行方式刷新或重启。
